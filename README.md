## 📁 Project Structure

This repository uses **separate branches** for frontend and backend:

- **`frontend`** branch → React Native mobile application
- **`OrbitBackend`** branch → Java EE REST API + WebSocket server

---

## 🛠️ Tech Stack

### Frontend
- React Native (Expo)
- TypeScript
- Reanimated
- NativeWind
- WebSocket Client

### Backend
- Java EE
- WebSocket API
- Hibernate ORM
- MySQL
- RESTful Services

---

## ✨ Features

- ✅ Real-time messaging with WebSocket
- ✅ User authentication & onboarding
- ✅ Contact synchronization
- ✅ Read receipts & unread badges
- ✅ Dark/Light theme toggle
- ✅ Real-time friend list updates
- ✅ Smooth animations & modern UI
